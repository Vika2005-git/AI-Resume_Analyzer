# AI Resume Analyzer

A full-stack resume analysis application built using Java, Spring Boot, MySQL, and Gemini AI.

## 🚀 Features

- Resume upload
- PDF and DOCX support
- Resume text extraction
- AI-powered resume analysis
- ATS score generation
- Key skills identification
- Strength and weakness analysis
- Recommended skills
- Improvement suggestions
- Overall resume assessment
- REST API
- Frontend integration
- Error handling

## 🛠️ Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Apache Tika
- Gemini API

### Frontend
- HTML
- CSS
- JavaScript

### Tools
- Postman
- Git
- GitHub
